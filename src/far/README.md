# far

Data-generating process for a functional autoregressive process of order 1 (FAR(1)):

    X_t(s) = ∫_0^1 psi(s, r) X_{t-1}(r) dr + eps_t(s),   t = 1, ..., n

with i.i.d. Gaussian-process innovations `eps_t`. `far_dgp` generates such a process, which
relaxes the i.i.d.-curves assumption made by `truncFLR.HH_dgp` and `fdaSP.SBC_sim` so the same
two estimators can be exercised on serially dependent data without modification. `far_est`
goes the other way: given curves, it estimates `psi` and tests whether there is any serial
dependence there to estimate.

## Modules

**`far_dgp.py`**: builds the operator, discretised with trapezium weights and rescaled to a
target Hilbert-Schmidt norm `rho`. A `rho < 1` is sufficient for the process to admit a
strictly stationary, causal solution (Bosq, 2000, Thm 3.1). `sample_far1` iterates the
recursion and discards a burn-in, so the returned curves are drawn from the stationary
distribution. `sim_dataset_window` and `sim_dataset_psi` are FAR(1) drop-in replacements for
`truncFLR.HH_dgp.sim_dataset` and `fdaSP.SBC_sim.simulate`, returning the same shapes.

Two kernels are supplied:

- `gaussian_kernel` — the Bosq (2000, Ch. 3) example `psi(s, r) = exp{-(s² + r²)/2}`. It
  factorises as `exp(-s²/2) exp(-r²/2)`, so the operator has **rank one**: only the component
  of `X_{t-1}` along `exp(-r²/2)` carries forward and every orthogonal direction is i.i.d.
  across `t`. Its Hilbert-Schmidt and operator norms coincide, at `rho`.
- `exponential_kernel` — `psi(s, r) = exp(-|s - r| / scale)`, which has full rank and
  eigenvalues decaying like `j^-2`, so every direction in L² is autocorrelated. Its operator
  norm is strictly below `rho`, and `scale` sets how far along the domain the dependence
  reaches.

The first is the paper's example; the second is the one that actually stresses the estimators,
since a rank-one operator leaves almost all of the covariance structure i.i.d.
`hs_norm`, `operator_norm` and `kernel_rank` report these properties for any operator.

**`far_est.py`**: estimation and inference, the counterpart to the above. `far1_fit` projects
the centred curves onto their leading `p` empirical principal components, regresses each score
vector on its predecessor, and reads the kernel back off the resulting `p x p` matrix (Bosq,
2000, ch. 8). The covariance operator's inverse is unbounded, so `p` regularises rather than
merely truncating, and `select_p` chooses it by held-out one-step forecast error rather than by
a variance-explained rule — which ranks components by how much of the *marginal* spread they
carry, and has no reason to know the order in which they carry the *dynamics*.

Two tests answer "is there serial dependence here at all", which has to be settled before a
fitted operator means anything:

- `portmanteau_test` — the multivariate Ljung-Box statistic of Gabrys & Kokoszka (2007) on the
  score vectors, referred to its chi-squared limit. Cheap, and blind to dependence living
  outside the leading `p` components.
- `permutation_test` — the same autocovariance norms referred to the distribution generated by
  reshuffling the curves. That *is* the i.i.d. null, conditional on the observed curves, with
  no appeal to a limit and no moment condition. On the heavy-tailed price curves of
  `notebooks/overnight_jumps.ipynb` it is the one to believe, and `tests/test_far_est.py`
  measures the size of both under the null rather than assuming it.

`rolling_forecast` scores a fitted model the only way that settles anything on real data: one
step ahead, out of sample, refitting on an expanding window, against the flat forecast. A
significant test and a negative `r2_oos` together are not a contradiction — they say the
dependence is real and is not in the conditional mean, which is all a FAR(1) can represent.

## Usage

```python
import numpy as np
from far import far_dgp

grid = np.linspace(0, 1, 301)
Psi = far_dgp.gaussian_kernel(grid, rho=0.7)

# FAR(1) analogue of truncFLR.HH_dgp.sim_dataset, goes straight into HH.fit_mirror
data = far_dgp.sim_dataset_window(n=200, grid=grid, u=0.8, v=1.0, snr=26.25, rho=0.7, rng=0)

# FAR(1) analogue of fdaSP.SBC_sim.simulate, goes straight into fdaSP.SBC.cv_fit
X, y, grid, beta_true = far_dgp.sim_dataset_psi(n=50, psi_fn=far_dgp.psi1, rho=0.7, rng=0)

# The full-rank kernel, which spreads the dependence across the whole space
X, y, grid, beta_true = far_dgp.sim_dataset_psi(n=50, kernel=far_dgp.exponential_kernel, rng=0)
```

Recovering an operator from curves, and asking first whether there is one:

```python
from far import far_est

X = far_dgp.sample_far1(500, grid, Psi, rng=1)
print(far_est.permutation_test(X, grid, max_lag=5, n_perm=999, rng=0)["p_value"])

p_hat = far_est.select_p(X, grid, p_range=range(1, 9))["p_hat"]
fit = far_est.far1_fit(X, grid, p=p_hat)
print(fit["hs_norm"], far_est.rolling_forecast(X, grid, p=p_hat)["r2_oos"])
```

`notebooks/FAR1_nonIID.ipynb` runs both scalar-on-function estimators on simulated FAR(1)
data; `notebooks/overnight_jumps.ipynb` runs `far_est` on real intraday price curves.

## Tests

`pytest tests/test_far_and_sim.py tests/test_far_est.py` — each kernel's Hilbert-Schmidt norm
and symmetry, its agreement with the integral operator it discretises, its rank, stationarity
of the sampled process after burn-in, and the serial dependence it induces along directions
orthogonal to `exp(-r²/2)`; `test_far_and_sim.py` also covers `fdaSP.SBC_sim`. The estimator
is checked against `far_dgp`, whose operator is known exactly, so kernel recovery has an
answer rather than a plausibility argument, and both dependence tests are checked for *size*
under the i.i.d. null as well as for power — a test that over-rejected would manufacture the
empirical notebook's conclusion.
